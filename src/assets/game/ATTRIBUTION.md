# Original game assets

The files in this folder are taken from 魔法少女ノ魔女裁判 (Magical Girl Witch
Trials) and are used with the rights holder's permission. Everything
else in the design (seal, rose windows, frames, icons) is rebuilt as SVG/CSS.

Scope:

| File | Source (AssetRipper export) | Used for |
| --- | --- | --- |
| `court.webp`, `court-m.webp` | `Naninovel/Backgrounds/MainBackground/RGB/Background_013_001.png` | landing atmosphere (fixed, ~40 % opacity, blurred, drifting); root OG plate |
| `wall.webp`, `wall-m.webp` | `Naninovel/Backgrounds/MainBackground/RGB/Background_014_001.png` | result screen + `/r/` + `/c/` page atmosphere; card and character OG plates |
| `profiles/<id>.webp` | `General/NonPacked/WitchBook/Profiles/Profile_<Name>.png` | the character OG portrait, and the file photo pinned to the warden's note on the special record |
